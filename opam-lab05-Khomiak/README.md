## Завдання 4. Вивід Count і Capacity

Початкова місткість K % 4 + 2 = 3, кількість викликів `Push` K % 4 + 3 = 4.

```
Початково: Count = 0, Capacity = 3
Push(1): Count = 1, Capacity = 3
Push(2): Count = 2, Capacity = 3
Push(3): Count = 3, Capacity = 3
Push(4): Count = 4, Capacity = 6
Peek: 4, Count після Peek: 4
```

На четвертому `Push` місця немає, масив подвоюється з 3 до 6. Завдання 1 на власному стеку дало ті самі результати, що й на `Stack<T>`, для всіх шести тестових рядків.

## Завдання 5. Обґрунтування

**Завдання 1 (стек).** Закривальна дужка має закривати найпізніше відкриту дужку, яка ще не закрита, тобто потрібен порядок «останнім прийшов, першим пішов», бо дужки вкладені одна в одну. Якби взяти чергу, закривальна дужка зіставлялася б із найпершою відкритою, і коректний рядок `"([])"` визнали б хибним, бо `]` зустрів би `(`. Список без стекової дисципліни довелося б вести вручну, відстежуючи останній елемент.

**Завдання 2 (стек).** Операція в зворотному польському записі бере два останні обчислені результати, тобто найсвіжіші значення. У виразі `2 3 4 * +` оператор `*` має отримати 3 і 4, а не 2 і 3. Якби взяти чергу, операція брала б найстаріші числа, і вираз дав би хибний результат; також порядок операндів для віднімання й ділення був би зіпсований.

**Завдання 3 (черга).** Заявки обслуговуються за принципом «першим прийшов, першим обслужений»: властивість задачі в тому, що чесний порядок визначається часом надходження. Якби взяти стек, першими обслуговувалися б останні заявки, а найраніші можуть чекати нескінченно (голодування), і всі часи початку були б іншими. Дві черги тут зберігають цей порядок усередині кожної групи, а пріоритет задається вибором, з якої черги брати.

**Чому `Queue.Dequeue()` дешевший за `List.RemoveAt(0)`.**
`List<T>` зберігає елементи у суцільному масиві, і після видалення першого елемента всі решта зсуваються на одну позицію вліво, тобто робота пропорційна довжині списку. За моїми замірами з лабораторної 4 вставка на початок списку (`Insert(0, x)`, яка зсуває елементи так само) для 100 000 елементів зайняла ___ мс, а `Add(x)` ___ мс, тобто різниця у ___ разів. `Queue<T>` влаштована як кільцевий буфер із вказівниками на голову й хвіст: `Dequeue` лише переміщує вказівник голови на наступну клітинку й елементи не копіює, тому коштує однаково незалежно від довжини черги.
