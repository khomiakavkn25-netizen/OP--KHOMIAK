# Лабораторна робота 2. Алгоритми обробки масивів

**Виконав:** Хом'як  
**Варіант:** N = 27, K = 26 (літера «Х»), a = 0, b = 3, c = 2  

---

## Структура методів

- `Task1_Aggregation` — Агрегація за один прохід (сума, середнє, мін/макс з індексами, кількість нулів).
- `Task2_Filter` — Фільтрація елементів > 1 у новий масив точного розміру (2 проходи).
- `Task3_Series` — Знаходження найдовшої серії однакових елементів підряд (з урахуванням закінчення на останньому елементі).
- `Task4_Permutation` — Циклічний зсув вправо на 1 позицію без створення другого масиву.
- `Task5_Matrix` — Побудова матриці 6x3, суми рядків, максимуми стовпців, номер рядка з найбільшою сумою (`GetLength(0)` та `GetLength(1)`).
- `Task6_EdgeCases` — Перевірка алгоритмів на крайових випадках.
